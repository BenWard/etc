# v2 Dotfiles Manual

This repo now uses Chezmoi as the dotfile manager and `just` as the command runner. Bash remains the supported interactive shell; the login shell can still be zsh as long as Bash startup files are applied into `$HOME`.

## Commands

Run these from the repo root:

```sh
just --list
just install
just diff
just apply
just doctor
just update
```

- `just install` installs or updates the Homebrew bundle, initializes Chezmoi with this repo as the source directory, force-applies the managed dotfiles, then runs `doctor`.
- `just diff` shows the changes Chezmoi would make in `$HOME`.
- `just apply` writes the Chezmoi-managed files into `$HOME`.
- `just doctor` checks required binaries, shell startup files, Chezmoi source readability, Atuin local-only config, `bash-completion@2`, and `brew bundle check`.
- `just update` runs `brew update`, applies the bundle, applies dotfiles, then reports mise and Homebrew outdated packages.

Preview before changing files:

```sh
chezmoi --source "$(pwd)" diff
chezmoi --source "$(pwd)" apply --dry-run --verbose
```

## Chezmoi Structure

The repo root contains a `.chezmoiroot` file that points Chezmoi at `home/` as the source-state root. That keeps the source tree separate from repo-only files.

Chezmoi source names map to home-directory targets:

- `home/.chezmoiignore` -> source-state ignore rules, including the real local Chezmoi config
- `home/.chezmoidata.toml` -> shared template data, including `userHostColor`
- `home/dot_bashrc` -> `~/.bashrc`
- `home/dot_bash_profile` -> `~/.bash_profile`
- `home/dot_gitconfig` -> `~/.gitconfig`
- `home/dot_AGENTS.md` -> `~/.AGENTS.md`
- `home/dot_claude/` -> `~/.claude/`
- `home/dot_codex/` -> `~/.codex/`
- `home/dot_config/atuin/config.toml` -> `~/.config/atuin/config.toml`
- `home/dot_config/chezmoi/chezmoi.example.toml` -> `~/.config/chezmoi/chezmoi.example.toml`
- `home/dot_config/mise/config.toml` -> `~/.config/mise/config.toml`
- `home/dot_config/starship.toml.tmpl` -> `~/.config/starship.toml`
- `home/dot_dotfiles_lib/bash/` -> `~/.dotfiles_lib/bash/`
- `home/dot_dotfiles_lib/git-aliases/executable_*.sh` -> executable helper scripts in `~/.dotfiles_lib/git-aliases/`

Generated files are regular files. The old Rake installer created symlinks; Chezmoi now writes managed file contents unless a future source file explicitly uses Chezmoi symlink attributes.

Repo-only files such as `Brewfile`, `justfile`, `docs/`, and `tools/` live outside the source tree and do not need ignore entries.

The real local Chezmoi config, `home/dot_config/chezmoi/chezmoi.toml`, is ignored by git and excluded from Chezmoi's target state. Use `~/.config/chezmoi/chezmoi.example.toml` as the starting point when setting machine-specific `[data]` values.

## Editing Workflow

Edit source files in this repo, then run:

```sh
just diff
just apply
```

If a managed file is edited directly in `$HOME`, bring it back into the source state:

```sh
chezmoi --source "$(pwd)" re-add ~/.bashrc
chezmoi --source "$(pwd)" diff
```

For one-off edits through Chezmoi:

```sh
chezmoi --source "$(pwd)" edit ~/.bashrc
chezmoi --source "$(pwd)" edit --apply ~/.bashrc
```

## Homebrew

`Brewfile` remains the package source of truth. It now installs the dotfile and shell tools needed by v2:

- `chezmoi`
- `just`
- `mise`
- `starship`
- `fzf`
- `zoxide`
- `atuin`
- `bash-completion@2`
- `bash-preexec`
- `ripgrep`

Runtime formulas now track current Homebrew packages: `node`. The stale `homebrew/php` tap, `node@16`, `php@7.4`, `phplint`, and `bash-completion` entries were removed.


Maintenance commands:

```sh
brew bundle check --file Brewfile --verbose
brew bundle install --file Brewfile
brew bundle cleanup --file Brewfile
```

## Bash Startup

`~/.bashrc` and `~/.bash_profile` both load:

```sh
source "$HOME/.dotfiles_lib/bash/loader.bash"
```

The loader keeps the old module shape under `~/.dotfiles_lib/bash`, but the tool integrations changed:

- `mise activate bash` replaces `nvm`, fixed PHP paths, fixed Node paths, fixed Ruby paths, and RVM startup.
- `starship init bash` replaces the handwritten prompt and git prompt annotation.
- `fzf --bash` adds fuzzy file, history, and completion bindings.
- `zoxide init bash` replaces autojump while preserving the `z` jump workflow.
- `starship init bash` runs before Atuin so Starship owns the prompt shape.
- `bash-preexec` loads before `atuin init bash`, which lets Atuin receive executed commands for local history recording.
- `atuin init bash` replaces plain reverse-history search behavior with local Atuin search and command capture.
- `bash-completion@2` replaces the old `bash-completion` formula.
- npm script completion is loaded explicitly from Homebrew's npm completion file when available, with `npm completion` as a fallback.
- Explicit Bash options replace the vendored `bash/sensible` submodule.
- Prompt color now comes from Chezmoi data and is rendered by Starship, not Bash.

The loader still accepts `~/.extras.bash` for local, untracked machine-specific additions.

## Prompt

Starship is configured in `home/dot_config/starship.toml.tmpl` to preserve the old prompt shape:

```text
[HH:MM] ~user@host ~/path#branch ± $
[HH:MM] ~user@host ~/path#branch = $
```

The marker is `±` when the repo has changes and `=` when the repo is clean. The host is omitted only on `Voyager.local`, matching the old prompt behavior. The `user_host` segment color comes from `userHostColor`: the repo default is in `home/.chezmoidata.toml`, and machine-specific overrides belong in the local Chezmoi config at `~/.config/chezmoi/chezmoi.toml` under `[data]`. `home/dot_config/chezmoi/chezmoi.example.toml` is deployed as a copyable example. The value is a semantic Starship color name, not a raw Bash escape sequence.

## History

Atuin is configured in `home/dot_config/atuin/config.toml` with `auto_sync = false`, `search_mode = "daemon-fuzzy"`, and daemon autostart enabled. The Bash integration requires Homebrew `bash-preexec`, which `just install` installs from the Brewfile and the Bash loader sources before `atuin init bash`. No cloud account, sync key, or sync address is configured by this repo.

Useful commands:

```sh
atuin search
atuin stats
atuin import bash
```

Run `atuin register`, `atuin login`, or `atuin sync` only if you intentionally want cloud sync later.

## Directory Jumping

`zoxide` provides the `z` command:

```sh
z project
zi project
```

Unlike autojump, zoxide learns from shell integration and ranks paths by frecency. The command feel stays the same for the common `z name` workflow.

## Runtimes With Mise

Use mise for runtime versions:

```sh
mise use -g node@latest php@latest ruby@latest
mise use node@20
mise install
mise current
```

To temporarily pin an old project runtime without restoring old PATH blocks:

```sh
cd /path/to/project
mise use node@16
mise use php@7.4
mise use ruby@2.7
mise install
```

Prefer project-local `.mise.toml` pins for legacy projects and global pins only when a runtime is broadly needed.

## Retained Helpers

These bespoke helpers remain:

- Docker Compose helpers: `dcshell`, `dcrun`, `dcpytest`
- Git helpers: `gitroot`, `git wt`, `git prune-local`, `github`
- Caire helper: `push-to-dev`
- Editor wrappers: `code`, `nova`, `subl`
- Utility helpers: `cdls`, `lsl`, `lsa`, `http`, `sudohttp`, `killport`, `urlencode`, `uuid`, `pycheck`

`hist` now wraps `atuin search --cmd-only --search-mode full-text` and post-filters command text when a query is provided, preserving the old `history | grep` shortcut behavior without surfacing Atuin prompt-hook artifacts. It prints a `running ...` line first so the command being invoked is explicit. If Atuin is unavailable, it falls back to `history | grep`.

## Removed Or Replaced

- `Rakefile` symlink installer -> Chezmoi plus `just`
- `colored` Ruby gem dependency -> no installer gem dependency
- `bash/sensible` submodule -> explicit Bash options in `home/dot_dotfiles_lib/bash/shell.bash`
- `nvm` shell loading -> `mise activate bash`
- `autojump` -> `zoxide`
- handwritten prompt and `git-prompt.sh` prompt dependency -> Starship
- fixed `node@16`, `php@7.4`, `ruby@2.7` PATH blocks -> current Homebrew formulas plus mise
- `phplint` -> removed from workstation baseline
- `bash-completion` -> `bash-completion@2`
